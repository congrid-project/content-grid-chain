Verifiers

Verifiers secure publisher quality by checking homepage badge ownership against on-chain records. Good verifier performance improves registry trust and can qualify for rewards.

Network values you'll use

  • Chain ID: {{.WalletConfig.ChainID}}
  • RPC: {{.WalletConfig.RPC}}
  • gRPC (example): 127.0.0.1:9090
  • Fee denom: {{if .WalletConfig.FeeDenom}}{{.WalletConfig.FeeDenom}}{{else}}ucongrid{{end}}
  • Suggested gas price: {{if .WalletConfig.GasPrice}}{{.WalletConfig.GasPrice}}{{else}}0.001ucongrid{{end}}

What verifiers do

  • Pull on-chain verification assignments.
  • Fetch publisher homepages and inspect Congrid badge link.
  • Submit accurate results in time windows.
  • Maintain high availability and consistent response latency.

Step 1 — Prepare wallet + stake

Use a dedicated verifier account. Keep enough balance for bonding and tx fees. 

# Bond (example amount)
./content-grid-d verifier bond 1000000 \
  --denom {{if .WalletConfig.FeeDenom}}{{.WalletConfig.FeeDenom}}{{else}}ucongrid{{end}} \
  --from <local-key-name> \
  --chain-id {{.WalletConfig.ChainID}} \
  --node {{.WalletConfig.RPC}} \
  --gas-prices {{if .WalletConfig.GasPrice}}{{.WalletConfig.GasPrice}}{{else}}0.001ucongrid{{end}} \
  -y

# Optional unbond later
./content-grid-d verifier unbond 1000000 \
  --denom {{if .WalletConfig.FeeDenom}}{{.WalletConfig.FeeDenom}}{{else}}ucongrid{{end}} \
  --from <local-key-name> \
  --chain-id {{.WalletConfig.ChainID}} \
  --node {{.WalletConfig.RPC}} \
  --gas-prices {{if .WalletConfig.GasPrice}}{{.WalletConfig.GasPrice}}{{else}}0.001ucongrid{{end}} \
  -y

Step 2 — Run verifier daemon

Use offchain/verifierd from this repository for chain-driven assignments. Run it continuously and monitor logs so you can submit checks inside each assignment window. 

# Example status checks
./content-grid-d verifier assignments <verifier-address> \
  --node {{.WalletConfig.RPC}} \
  --grpc-addr 127.0.0.1:9090 \
  --grpc-insecure -o json

./content-grid-d query registry publisher --domain <domain> \
  --node {{.WalletConfig.RPC}} \
  --grpc-addr 127.0.0.1:9090 \
  --grpc-insecure -o json

Docker operator stack

For unattended operation, use the repository Docker Compose stack. It runs a node plus the required verifier support services: chromad, indexerd, and verifierd. Here, verifierd is the Congrid publisher verifier, not a Cosmos consensus validator. 

# Prepare operator env and secret files
cp docker/operator.env.example .env.operator
mkdir -p docker/network docker/secrets

# Put the network genesis at docker/network/genesis.json, then edit .env.operator:
# - CONGRID_CHAIN_ID={{.WalletConfig.ChainID}}
# - CONGRID_GENESIS_FILE=/network/genesis.json
# - CONGRID_PERSISTENT_PEERS=<node-id>@<host>:26656,...
# - CONGRID_KEYRING_BACKEND=file
# - CONGRID_VERIFIER_KEYRING_DIR=/var/lib/congrid/keyrings/verifier
# - CONGRID_VERIFIER_KEY_MNEMONIC_FILE=/run/congrid-secrets/verifier.mnemonic
# - CONGRID_VERIFIER_KEYRING_PASSPHRASE_FILE=/run/congrid-secrets/verifier.passphrase

# Store these files outside git history.
$EDITOR docker/secrets/verifier.mnemonic
$EDITOR docker/secrets/verifier.passphrase

# Start the verifier stack
docker compose --env-file .env.operator -f docker-compose.operator.yml up -d --build \
  node chromad indexerd verifierd

# Optional: run drand-relayer too if the network uses drand-backed assignment randomness
docker compose --env-file .env.operator -f docker-compose.operator.yml --profile drand up -d --build \
  drand-relayer

# Watch verifier progress
docker compose --env-file .env.operator -f docker-compose.operator.yml logs -f verifierd

The Docker entrypoint generates the verifierd config from env values. The important long-running defaults are CONGRID_VERIFIER_COMMIT_START_BUFFER_SECONDS=15, CONGRID_VERIFIER_TX_INCLUSION_TIMEOUT_SECONDS=120, and CONGRID_VERIFIER_STATE_DIR=/var/lib/congrid/verifierd-state, which persists pending commit/reveal nonces across restarts. 

# Confirm the verifier address resolved by verifierd
docker compose --env-file .env.operator -f docker-compose.operator.yml logs verifierd | \
  grep 'starting verifierd verifier='

# Confirm assignments and successful submissions from the host
./content-grid-d verifier assignments <verifier-address> \
  --node {{.WalletConfig.RPC}} \
  --grpc-addr 127.0.0.1:9090 \
  --grpc-insecure \
  --include-finalized -o json

Step 3 — Keep your verifier reliable

  • Use stable DNS/network; avoid frequent IP rotations.
  • Track failed checks and homepage fetch latency.
  • Alert on process exit, RPC disconnect, and backlog growth.
  • Keep software updated with protocol changes.
Verifier tip: Reliability matters because missed or inaccurate checks reduce your reward potential.

# 内容网格代币经济学

本文档描述了此存储库中的**当前链上行为**。

## 供应和分配基线

- 单位：`ucongrid` (1 CONGRID = 1,000,000 `ucongrid`)
- 参考总供给参数：**1,000,000,000 CONGRID** (`1_000_000_000_000000 ucongrid`)
- 排放分割默认值（注册表参数）：
  - 操作员储备金：**40%** (`operator_reserve_bps=4000`)
  - 发布商排放量：**10%** (`publisher_emission_bps=1000`)
  - 验证者排放：**50%** (`verifier_emission_bps=5000`)
- 发射持续时间默认值：**100 年**（`876,000` 小时）

## 每小时排放量（当前默认值）

对于 `round_interval_seconds=3600`，默认映射为：

- 每小时发布者池：**114,155,251 ucongrid** (~114.155251 CONGRID)
- 每小时验证者池：**570,776,255 ucongrid** (~570.776255 CONGRID)

这些值由 `PublisherParams.RoundEmissionPools(...)` 计算。

## 奖励如何支付（当前实施）

注册表验证奖励在回合结束时以 `x/registry` 支付。

1. 链计算每轮发布者/验证者池。
2. `tokenomics` 模块确保/保持排放池平衡。
3. 支出是**基于模块池** (`SendFromPool`) 的转移，而不是按每个接收者铸造。
4. 无人认领的部分将从池中烧毁（`BurnFromPool`）。

## 发布者奖励规则

- 发布商池在该轮的活动分配中平均分配。
- 仅当满足所需的外部链接阈值时，发布商才能声明完全共享：
  - `required_external_links_for_full_reward`（默认`15`）
- 如果低于阈值，则按比例索赔。
- 无人认领的发行商金额将被烧毁。

# 治理手册

本手册记录了运行时接线落地后，内容网格链如何使用 `x/gov` 管理货币政策和运营决策。

## 提案类型

- **参数变化**：调整货币杠杆（通胀带、奖励分割、费用比率）。需要 2 周的投票期、40% 法定人数、55% 绝对多数。
- **预算分配**：从社区金库中提取。必须包括基于里程碑的付款计划和责任检查点。
- **模块权限授予**：暂时授予自定义模块铸造或托管资金的能力。默认有效期：6 个月。
- **紧急响应**：停止通货膨胀或削减修复池的收益。通过 48 小时投票和 2/3 批准的加急提案触发。

## 流程概述

1. **启动**：起草提案内容（Markdown/JSON）并收集链下反馈。
2. **参数审核**：针对建议的参数运行 `go run ./cmd/tokenomics simulate ...` 以记录预期的供应影响。
3. **提交**：治理布线落地后使用 CLI（占位符命令 `content-grid-d tx gov submit-proposal`）。
4. **投票**：验证者传达理由，观察者验证参数安全性，社区频道主持辩论。
5. **颁布**：投票期和存款通过后，事后总结将进入治理档案库。

## 货币护栏

- 如果没有 3/5 法定人数和 2/3 赞成票，则无法修改通货膨胀界限 (`[0.04, 0.12]`)。
- 除非附有正式的经济分析附件，否则奖励分配必须保持在默认值的±5%以内。
- 如果没有链上续订，任何提案都不得授予 `MintCoins` 超过 12 个月的权限。

## 资金管理

- 国库支出通过多重签名手动流式传输，直到自动流式传输 (x/authz) 落地。
- 每个预算提案必须指定关键绩效指标和报告节奏；后续资金部分取决于 KPI 证明。
- 紧急储备金（国库的10%）用于安全事件；利用它需要紧急提案。

## 紧急检查表

- 快照指标（质押比率、奖励队列、财务余额）。
- 使用建议的紧急参数运行 `tokenomics simulate` 以确保稳定性。
- 如果需要，协调验证器进行软件/配置更改（例如，通过参数补丁停止通货膨胀）。
- 在事件解决后 72 小时内发布事后分析。

## 文档

- 将提案草稿、模拟和审核注释存储在 `gov-records/` 目录中（运行时接线完成后添加）。
- 与任何治理模块升级一起更新此剧本。
